The chandelier and wall sconce contain editable point lights. All models use the project's shared purple, black, cream, gold, cyan, pink, and green materials. No textures or third-party assets are used, so this batch adds no external license obligations.

Use the **New Props Showcase** preset to inspect the complete batch together. Material overrides, scaling, mirroring, duplication, collections, collision previews, and JSON export work through the normal editor controls.
