# Character Asset Licensing

All 30 villain character designs, procedural source geometry, materials, and exported GLBs in this directory are original project assets created for *Hotel for Supervillains: The Grand Disaster*.

No third-party character models, textures, rigs, copyrighted villain designs, or external visual assets are included in these exports.

The export pipeline uses Three.js and its GLTFExporter. Three.js is distributed under the MIT License; the vendored license is available at `3d/vendor/THREE_LICENSE.txt`.
